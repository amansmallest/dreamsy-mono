# procgen kit

The "vast but cheap" lever: seeded, deterministic generators whose output drops straight into TileMap2D `data`
strings and spawn lists. Same seed ⇒ same output on every device/server/test. Every map generator guarantees
connectivity (BFS-validated, retried internally) and returns a `report`. Example: `games/examples/kit-roguelike-demo`
(rooms-stitched, rooms-and-corridors and cave floors, budgeted enemies, loot, a boss every 3rd floor).

## Setup
```luau
local procgen = require("@kit/procgen")
local level = procgen.dungeon({ seed = runSeed * 1000 + floor, w = 30, h = 30, rooms = 8 })
entity("map").data = procgen.toTileMap(level, { ["."] = "f" })   -- "." is always empty in TileMap2D: map floor to a tile char
local x, y = procgen.cellToWorld(level.start.x, level.start.y, 16)  -- map at (0,0)
```
Grid chars: `#` wall, `.` floor (configurable `wall`/`floor`). Cells are 0-based like TileMap2D.

## RNG + noise
```luau
local r = procgen.rng(seed)   -- number or string; independent of engine random()
r:next() [0,1)   r:int(a, b) inclusive   r:range(a, b)   r:chance(p)   r:sign()   r:pick(list)   r:sample(list, n)
r:weighted(list (item.weight) | {key = weight} | list, weightFn)   r:shuffle(list)   r:gauss(mean, sd)   r:fork("label")   r:clone()
procgen.noise.value1(x, seed)  value2(x, y, seed)  simplex2(x, y, seed)  fbm1(x, opts)  fbm2(x, y, { octaves=4, scale=1, gain=0.5, lacunarity=2, kind="simplex"|"value", seed })  -- ≈ [-1,1]
```

## Maps (all take `seed` or `rng`; return `level = { grid, start, exit, spawns?, markers?, report }`)
```luau
procgen.dungeon({ w=48, h=48, rooms=10, minRoom=4, maxRoom=9, loops=0.15, corridor=1, enemies={1,3}, items={0,1} })
  -- + level.rooms {id,x,y,w,h,cx,cy,dist}, level.spawns {kind="enemy"|"item", x, y, room} (cells), exit = farthest room
procgen.rooms({ templates = { start_a = "text", room_1 = "text", key_vault = "...", exit_boss = "..." } | { {id, grid, tags, weight} },
                rooms = 6 (main path), branches = 2, key = true, door = "+", keyChar = "k", exitChar = ">", markers = "floor"|"keep" })
  -- hand-made same-size chunks stitched on a room grid; key placed in a side room, exit room behind a locked door:
  -- guaranteed start→key without the door and start→exit through it. Template chars: # . ? (random) + markers (E, T, B…)
  -- → level.markers {char, x, y, room}, level.key, level.door, level.rooms {id, template, role = start|path|side|key|exit}
procgen.caves({ w=48, h=48, fill=0.45, steps=5, minOpen=0.35, enemies=8, items=3, minSpawnDist=8 })   -- largest region only
procgen.terrain({ w=64, h=64, scale=0.06, octaves=4, island=0..1, biomes = procgen.BIOMES, connect=true })
  -- → grid of biome chars (~ deep water, w water, s sand, g grass, f forest, d desert, S snow, M mountain), biomeAt(x,y), start
procgen.chunks.sequence({ chunks = { {id, grid, difficulty=0..10, tags={"start"|"end"}} }, length=8, from=1, to=6, spread=1.5, solid="#=", maxStep=3 })
  -- platformer level: chunks concatenated left→right with a difficulty ramp + ground-height matching → { grid, sequence, difficulties }
procgen.chunks.reachable(grid, { solid="#=", hazard="^", jump=3, run=4, from?, to? }) -> { ok, reached, standable }
```

## Output + checks
```luau
procgen.toTileMap(level|grid, { [genChar] = tileChar }) -> "rows\n..."            -- TileMap2D data
procgen.spawnList(level, { tileSize=16, origin={x,y}, markers = { E = "enemy", T = "chest" }, assign = { enemy = fn(rng, s) -> id } })
  -> { {kind, x, y (world centre), cell={x,y}, id?, room?} }
procgen.scatter(level|grid, n, { seed, pass=".", from=level.start, minDist=6 (BFS steps), gap=2 }) -> { {x,y} cells }
procgen.validate(grid|text, { pass = nil (not "#"/" ") | "chars" | set | fn, from = {x,y}, targets = { {x,y,name?} }, requireAll = true })
  -> { ok, reachable, total, regions, unreachable = {...}, missing, distances = {[name]=steps}, problems = {"..."} }
procgen.grid(w, h, fill) / procgen.fromString(text) -> Grid: get set fill blit clone count find toString flood regions
```

## Content generators
```luau
procgen.loot.roll(table, rng|seed, { tables = allTables (nested "table" entries), state = saveTable (pity counters) }) -> { {item, count, rarity} }
procgen.loot.odds(table) -> { item = probability per roll }
procgen.waves.encounter(enemies, budget, rng, { level = floor, tags?, minCount = 1, maxCount = 12 }) -> { ids, cost }
  -- enemies: { {id, cost=1, weight=1, minLevel, maxLevel, max, tags} } (your data/enemies/*.json)
procgen.waves.waves(enemies, { count=10, budget=6, growth=1.35, add=0, boss={id, every=5}, gap=1, seed }) -> { {wave, budget, cost, ids, spawnTimes} }
procgen.names.markov(trainingNames, order=2).make(rng, { min=4, max=9 })     -- "Kalvorin"
procgen.names.fill("The {adj} {noun} of {Ash|Frost}", { adj = {...}, noun = {...} }, rng)   procgen.names.syllables(parts, rng, 2, 3)
```

## Puzzles (generated by reverse play, verified by a solver; difficulty = optimal solution length)
```luau
procgen.puzzle.sokoban({ seed, w=8, h=8, boxes=2, walls=0.12, minPushes=4, maxPushes=30 }) -> { text (XSB: # wall, - floor, @ player, $ box, . goal, * box on goal, + player on goal), pushes, moves ("lurdLURD", caps = push) } | nil
procgen.puzzle.solveSokoban(text, { maxStates = 200000 }) -> { solvable, pushes, moves }
procgen.puzzle.sliding({ seed, n=3, minMoves=8, maxMoves=20 }) -> { board (flat, 0 = blank), n, moves, path, text }   solveSliding(board, n)
procgen.puzzle.lightsOut({ seed, w=5, h=5, minPresses=4, maxPresses=8 }) -> { lit (flat bools), presses, solution, text ("o" lit) }
procgen.puzzle.solveLightsOut(lit, w, h) -> min-press cell list | nil     procgen.puzzle.pressLightsOut(lit, w, h, i)
```

## Content files (schemas/)
`data/rooms/<id>.txt` (grid only; tags from id prefix `start_` `exit_`/`boss_` `key_`/`treasure_`, others normal) or `.json` (`room.json`),
`data/chunks/<id>.json` (`chunk.json`), `data/loot/<id>.json` (`loot.json`), `data/biomes/<id>.json` (`biomes.json`),
`data/words/<id>.json` (`words.json`), `data/waves/<id>.json` (`waves.json`). Load them with the engine data reader:
`procgen.load("rooms")` → `{ [id] = text|table }`; `procgen.content({ "enemies", "loot", "rooms" }?)` → `{ enemies = {…}, loot = {…}, … }`
(json id = `id` field or file name; `.txt` trimmed). Don't generate `scripts/shared/*content*.luau` copies.

## Do / don't
- Do derive every floor's seed from one run seed (`runSeed * 1000 + floor`) so runs are replayable/shareable.
- Do keep one generator call per frame under the 250 ms script budget: dungeon 30×30 ≈ 3 ms, caves 40×40 ≈ 18 ms, terrain 48×48 ≈ 25 ms,
  sokoban (8×8, 2 boxes) ≈ 10–60 ms. Big worlds: generate in chunks across ticks.
- Do give room templates connected interiors; `?` cells may wall things off (pockets are walled up automatically).
- Don't use "." as a tileset char (always empty); map generator chars with `toTileMap(level, { ["."] = "f" })`.
